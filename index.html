🛠️ Guia do Modificador

Como remover anúncios e desbloquear o Premium

🛠️ Ferramentas Necessárias

  • MT Manager / Dex Editor Plus: Para mexer no código (Smali) e remover anúncios.
  • Lucky Patcher: Para desbloquear o Premium (a forma mais fácil).

⭐ Regra de Ouro: Assinar o APK

Sempre que você modificar qualquer coisa no MT Manager, você precisa assinar o APK de novo, senão o Android não deixa instalar.

No MT Manager: Ao sair, ele pergunta se quer assinar. Diga Sim. Ou vá no menu do APK > Assinar.
IMPORTANTE: Marque sempre a opção "Remover Verificação de Assinatura" (Signature Kill). Isso impede que o app feche sozinho após ser modificado.

📺 Passo 1: Remover Propagandas (Anúncios)

Use o MT Manager para isso. A propaganda está no código Smali.

Como fazer:
1. Abra o APK no MT Manager e vá em Dex.
2. Pesquise por termos como: showAd, loadAd, AdView, Interstitial.
3. Abra o método que encontrar. Você verá um monte de código.
4. Apague tudo o que tem dentro e substitua por: return-void.
Isso faz o app "pular" a propaganda.

👑 Passo 2: Desbloquear Premium (Método Fácil)

Não tente mexer no código para o Premium. Use o Lucky Patcher.

Como fazer:
1. Abra o Lucky Patcher e ache o app.
2. Toque em Menu de patches (ou Patches Personalizados).
3. Procure por nomes como gnom_Pro ou ZONE_ADRIAN (são patches feitos por especialistas).
4. Marque a caixinha do patch e clique em Patchear.
5. NÃO marque as opções de "Burlar verificação" na tela final do Lucky Patcher, pois o patch já faz isso sozinho.
6. Recompile, instale e teste a compra. O Lucky Patcher vai fingir que você pagou!

⚠️ Passo 3: Desbloquear Premium (Método Difícil - MT Manager)

Use isso apenas se o Lucky Patcher falhar e o app for simples.

Como fazer:
1. No MT Manager, pesquise por: isPremium, isPro, isVip, hasPurchased.
2. Procure por métodos que terminam com ()Z (Z significa que retorna True ou False).
3. O código vai se parecer com isso:
const/4 v0, 0x0
return v0
4. Mude o 0x0 (Falso) para 0x1 (Verdadeiro).
const/4 v0, 0x1
return v0
Isso força o app a achar que você é VIP.

🚫 O que NUNCA fazer

  • Não atualize pelo Google Play: Se atualizar, o app original volta e você perde o mod.
  • Não desative o Google Play Protect: Você pode precisar desativá-lo temporariamente para instalar o APK modificado, mas ligue-o de novo depois.
  • Não compartilhe com desconhecidos: Modificar apps é para uso pessoal. Distribuir pirataria pode dar problema.
Este guia é para fins educacionais e de aprendizado em engenharia reversa. Sempre apoie os desenvolvedores comprando a versão original se puder.
